# W3-4 — Subcontractor portal + Homeowner portal (EH-N + EH-O) handoff

- **Date:** 2026-05-15
- **Slice:** W3-4 (greenfield)
- **Status:** Complete; vue-tsc clean; 242 unit tests pass.
- **ADRs:** ADR-0031 (sub portal), ADR-0032 (homeowner portal).

## What shipped

### New role + DB

- `homeowner` added to `RoleSchema` (`shared/contracts/_shared.ts`),
  `users.roleEnum` (`server/db/schema/users.ts`), `ALL_ROLES`
  (`shared/auth/default-permissions.ts`), and `ROLE_GROUPS`
  (`app/composables/usePermissions.ts`).
- New tables: `subcontractor_users`, `subcontractor_coi_docs`,
  `homeowner_users` (all under `server/db/schema/`, exported from
  the barrel).

### Contracts + events

- `shared/contracts/subcontractor.ts` — `SubcontractorUserSchema`,
  `SubInviteInput/Output`, `SubcontractorCoiDocSchema`,
  `SubCoiUploadInput`. `ISubcontractorService` extended with
  `listUsers / inviteUser / removeUser / resolveSubForUser /
  listMyAssignments / listMyQuotesRequested / listCois / uploadCoi /
  scanCoiExpiry`.
- `shared/contracts/homeowner.ts` (new) — `HomeownerKind`,
  `HomeownerUser`, `HomeownerInviteInput/Output`, `IHomeownerService`.
- `shared/contracts/quote.ts` — `respondToQuote` added to
  `IQuoteService` (sub accepts/declines a requested quote).
- `shared/contracts/services.ts` — `homeowner: IHomeownerService`
  added to `BulwarkServices`.
- `shared/contracts/label.ts` — six new label namespaces
  registered (`sub.tabs`, `sub.coi`, `sub.quote`, `homeowner.tabs`,
  `homeowner.quote`, `homeowner.empty`).
- `shared/events/catalog.ts` — seven new events:
  `subQuoteResponded`, `subCoiUploaded`, `subCoiExpiringSoon`,
  `homeownerInvited`, `homeownerAccepted`, `homeownerQuoteViewed`,
  `homeownerInvoiceViewed`. All wired into `AnyDomainEventPayload`.
- `shared/notifications/templates.ts` — render functions for the
  seven new events.

### Services + factories

- `shared/mocks/subcontractor.mock.ts` — implements all nine new
  methods in-memory; exports `__resetSubcontractorMock` for tests.
- `shared/mocks/homeowner.mock.ts` (new) — implements
  `IHomeownerService`; exports `__resetHomeownerMock`.
- `shared/mocks/quote.mock.ts` — `respondToQuote` added.
- `server/services/subcontractor.real.ts` — real implementations.
  `inviteUser` creates a user (find-or-create), an idempotent
  `memberships` row (role `sub_contractor`), the join row, and a
  hashed `pending_invites` token with 7-day expiry. COI methods
  insert + audit + emit; `scanCoiExpiry` queries the window and
  emits `subCoiExpiringSoon` per row.
- `server/services/homeowner.real.ts` (new) — mirror of the sub
  invite flow for the homeowner role, emits `homeownerInvited`.
- `server/services/quote.real.ts` — `respondToQuote` audit-logged +
  emits `subQuoteResponded`.
- `shared/mocks/factory.ts` and `server/utils/services-factory.ts`
  both register the new `homeowner` service.

### UI surface

- New layouts: `app/layouts/sub.vue`, `app/layouts/homeowner.vue`.
- New middleware: `app/middleware/sub-role.ts`,
  `app/middleware/homeowner-role.ts`.
- New pages:
  - `app/pages/sub/index.vue` (home), `dashboard.vue` (redirect),
    `work-orders.vue`, `quotes.vue`, `cois.vue`, `settings.vue`,
    `profile.vue` (redirect).
  - `app/pages/homeowner/index.vue` (home), `properties.vue`,
    `quotes.vue`, `invoices.vue`.
- `app/pages/index.vue` and `app/pages/accept-invite.vue` redirect
  `sub_contractor` → `/sub` and `homeowner` → `/homeowner`.
- `shared/nav/nav.config.ts` — five sub entries + four homeowner
  entries; the legacy single `/sub/dashboard` row was replaced.
- `shared/labels/defaults.ts` — six new namespaced label groups.

### Background work

- `server/jobs/coi-expiry-check.ts` — host-side wrapper that calls
  `subcontractor.scanCoiExpiry` per org.
- `server/api/jobs/coi-expiry-check.post.ts` — admin-only POST
  endpoint that triggers the scanner.

### Tests

- `tests/unit/sub-portal.test.ts` — invite/list/remove flow + COI
  round-trip + quote response.
- `tests/unit/homeowner-portal.test.ts` — invite/list/remove flow.
- `tests/unit/coi-expiry.test.ts` — bucketing under/over the 30-day
  default and an explicit window.
- Lint test (`tests/unit/labels.test.ts`) updated implicitly by
  registering the six new namespaces in `LabelNamespaceSchema`.
