## Decisions made (flag if you disagree)

1. **PLATFORM_ORG_ID = nil uuid** for cron-run job rows — matches the
   existing `logSystemError` sentinel; `jobs.organization_id` has no FK.
   Tenant lists never see these rows; only the super-admin surface reads them.
2. **`listRecentRuns` refuses a tenant-resolver construction** — platform
   reads must come from the role-gated route, constructed resolver-less like
   the worker. Loud failure beats silent cross-tenant listing.
3. **Worker jobs-row status flips per attempt** (failed → running → succeeded
   across retries). The row reflects the latest attempt; `_runSummary` in
   payload records the last success. Documented in worker header.
4. **Templates = tenant wording, single layout.** The templates page edits
   the `pdf.*` labels the renderer consumes; visual variants are explicitly a
   non-goal, stated in the page header (not a "coming soon").
5. **Homeowner invoice PDF**: promise removed from UI; the feature itself is
   still L11 scope (unchanged).
6. **Reenqueue only from `failed`** — generating/ready docs throw
   "Invalid state…" (maps to 400 via dispatcher).
