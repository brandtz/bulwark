## What shipped

### Search (EH-P)

- **Contract** [`shared/contracts/search.ts`](../../shared/contracts/search.ts)
  - `SearchEntityType` enum + `SearchResult` (`{entityType, id, title, subtitle, url, score, organizationId}`)
  - `ISearchService.search(input)` returns `{results, hasMore}`
  - `scoreSearchHit(query, title, subtitle)` — pure scorer, exported for tests
- **Mock** [`shared/mocks/search.mock.ts`](../../shared/mocks/search.mock.ts)
  - `MockSearchService` with `registerAdapters([{entityType, listForOrg}])`
  - Adapters wired in [`shared/mocks/factory.ts`](../../shared/mocks/factory.ts) for property/client/quote/work-order/invoice/subcontractor
- **Real** [`server/services/search.real.ts`](../../server/services/search.real.ts)
  - One `AdapterRunner` per entity type using Drizzle `ilike`
  - Tenant-firewalled via `assertSameTenant(resolver, input.organizationId)`
  - Per-type cap 20, global cap from `input.limit` (max 50, default 20)
- **Factory** [`server/utils/services-factory.ts`](../../server/utils/services-factory.ts)
  - `new RealSearchService(tenantResolver)` constructed per request

### Saved views (EH-P)

- **Schema** [`server/db/schema/saved_views.ts`](../../server/db/schema/saved_views.ts)
  - Migration `server/db/migrations/0009_free_clea.sql`
  - Index `saved_views_org_user_entity_idx` on `(organizationId, userId, entityType)`
- **Contract** [`shared/contracts/saved-view.ts`](../../shared/contracts/saved-view.ts)
  - `ISavedViewService.{list, get, create, update, softDelete, setDefault}`
- **Real** [`server/services/saved-view.real.ts`](../../server/services/saved-view.real.ts)
  - All mutations inside `withAudit({ tx, audit })`
  - `clearSiblingDefaultsTx(tx, keepId, org, entityType, userId)` runs in the same tx
- **`BulwarkServices`** [`shared/contracts/services.ts`](../../shared/contracts/services.ts) gains `search`, `savedView`

### Observability (EH-Q)

- **Logger** [`server/utils/logger.ts`](../../server/utils/logger.ts)
  - `log(level, message, fields)` — JSON line per call
  - `BULWARK_LOG_LEVEL` env (default `info`)
  - `redactFields()` scrubs sensitive keys
- **Metrics** [`server/utils/metrics.ts`](../../server/utils/metrics.ts)
  - 7 pre-seeded counters via `COUNTERS` const
  - `incCounter(name, by?)`, `readCounter(name)`, `snapshotMetrics()`
- **Middleware** [`server/middleware/request-context.ts`](../../server/middleware/request-context.ts)
  - `requestId` per request on `event.context`
  - Increments `requests_total`, `requests_errored_total`
  - Logs `request.start` + `request.complete`
- **Endpoints**
  - [`server/api/health.get.ts`](../../server/api/health.get.ts) — public liveness
  - [`server/api/ready.get.ts`](../../server/api/ready.get.ts) — public readiness (`SELECT 1`)
  - [`server/api/metrics.get.ts`](../../server/api/metrics.get.ts) — admin-only JSON snapshot
- **Audit** `IAuditService.logSystemError({organizationId?, kind, message, metadata?})` — never throws
- **Console replacement** in 6 paths: `audit.real.ts`, `_queue/index.ts`, `webhook-deliver.ts`, `webhook-dispatcher.ts`, `notification-subscriber.ts`, and the new `request-context.ts` middleware

## Rollback plan

- Migration `0009_free_clea.sql` is additive (new `saved_views` table only) — `DROP TABLE saved_views CASCADE;` rolls back cleanly.
- Removing `search` + `savedView` from `BulwarkServices` is the only required code rollback; the new files (`search.{contract,mock,real}`, `saved-view.{contract,mock,real}`, `logger.ts`, `metrics.ts`, `request-context.ts`, `health.get.ts`, `ready.get.ts`, `metrics.get.ts`) can be deleted without touching existing entities.
