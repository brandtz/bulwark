# L06 — Data Layer Hardening

> **Phase:** A (Wave 1) · **Autonomy:** AUTO · **Depends on:** —
> **Owns gap-register:** §3.6.1–3.6.5 · **Decision:** ADR-0010 (truth) + perf budget (L10)

## Purpose
The schema is functionally complete but performance- and correctness-thin: hot tables
lack composite indexes, user-facing sequence numbers (quote/invoice) are generated by
`COUNT(*)+LIKE` with a race and **no UNIQUE constraint**, deep pagination scans skipped
rows, and a couple of list endpoints risk N+1. This epic makes the data layer
production-safe and is a prerequisite for the L10 perf budget.

## Key decisions
- Indexes added via a single additive migration; no column drops.
- Sequence numbering becomes **race-safe**: a per-(org, entity, year) counter row updated
  `... RETURNING` inside the same transaction as the insert, **plus** a UNIQUE constraint as
  the backstop; on conflict, retry once.
- Pagination keeps offset for shallow pages but adds an **opt-in cursor** (`afterId`/
  `afterCreatedAt`) for large lists and exports.
- N+1 fixes use Drizzle joins / batch loads; verified by query-count assertions.

## Stories

### L06-S1 — Composite indexes on hot tables
- **Schema/migration:** add partial composite indexes (WHERE `deleted_at IS NULL`) on
  `properties(org_id,status,created_at desc)`, `quotes(org_id,status,created_at desc)`,
  `invoices(org_id,status,created_at desc)`, `work_orders(org_id,status,created_at desc)`,
  `inspections(org_id,property_id,created_at desc)`; FK-side indexes where missing.
- **Tests:** integration — `EXPLAIN` shows index usage on the primary list query for each
  table (assert no seq scan on seeded volume).
- **Acceptance:** new migration applies cleanly; list queries index-backed.

### L06-S2 — Race-safe quote/invoice numbering + UNIQUE
- **Schema:** `org_number_counters(org_id, entity, year, last_seq)` (or reuse `org_settings`);
  UNIQUE on `quotes(quote_number)` and `invoices(invoice_number)`.
- **Server:** `quote.real.ts`/`invoice.real.ts` `next*Number` use the counter row
  (`UPDATE ... SET last_seq = last_seq+1 RETURNING`) inside the create tx; on UNIQUE
  conflict retry once. Remove the COUNT+LIKE TODO.
- **Tests:** integration — N concurrent creates for one org produce **distinct** sequential
  numbers; UNIQUE violation path retries and succeeds.
- **Acceptance:** no duplicate numbers under concurrency; constraint enforced.

### L06-S3 — Cursor pagination option for large lists/exports
- **Contract:** extend pagination schema with optional `afterId`/`afterCreatedAt`; reject
  `page > 1000` on the offset path.
- **Server:** add cursor support to the highest-volume list methods (properties, quotes,
  invoices, audit-log, notifications); CSV/export uses the cursor stream.
- **Tests:** unit — cursor walks the full set without dup/skip; offset cap returns 400.

### L06-S4 — N+1 elimination on list endpoints
- **Server:** audit `property.list` (per-row client) and compliance-doc list (per-doc job);
  replace with joins/batch loads.
- **Tests:** integration — query-count assertion: listing K rows issues O(1) queries, not O(K).
- **Acceptance:** no N+1 on the audited endpoints.

### L06-S5 — Index/constraint audit sweep + doc
- **Task:** EXPLAIN-sweep the remaining org-scoped list/filter queries; record results in
  `docs/DATA_LAYER.md` (table → primary query → index used); add any missing indexes.
- **Acceptance:** every org-scoped list query is index-backed or explicitly noted as small/static.
